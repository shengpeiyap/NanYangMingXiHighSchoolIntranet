我是南洋鸣溪中学 2004 年的毕业生，以前大家都叫我小美。

二十二年前，我的同学林子轩在学校机房出了事。那天是期末考的前一晚。

学校的旧内联网早就应该关掉了。可是上个月，我发现它还开着。网址没变，访客计数器还在跳。他的学号 04108，还在考场名单上。

我进去过一次，是 2016 年，他走后的第十二年。那次之后，我就不敢再进去了。我说不上为什么，只记得那天晚上，我关不掉那个网页。

我手上还有一张他留给我的软盘，标签上写着：**给小美——考完再看**。二十二年了，我一直没有打开。

所以我想拜托一个陌生人，帮我进去看看：**他到底考完了没有。**

登录的时候，随便填一个名字就可以。拜托了。

还有——如果网页叫你做什么，别全信。
